Install

Bootstrap once, then use the project-local command.

npx is only the installer path. After bootstrap, run Spectra through ./spectra/bin/spectra unless you installed the native binary.

Existing project with npm

cd existing-project
npx spectra-pack@latest adopt .
./spectra/bin/spectra onboard
./spectra/bin/spectra check
./spectra/bin/spectra status

Use adopt for a repository that already has application code. Spectra writes its own layer under spectra/ and leaves the product structure alone.

New project with npm

mkdir my-product
cd my-product
git init
npx spectra-pack@latest init .
./spectra/bin/spectra check

macOS or Linux without Node

curl -fsSL https://raw.githubusercontent.com/yunusakin/spectra/main/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"
spectra version
spectra adopt .

The native installer downloads the matching release artifact and verifies its checksum. Keep the PATH export in your shell profile if you want spectra available in new terminals.

Update flow

./spectra/bin/spectra update
./spectra/bin/spectra check
./spectra/bin/spectra status

Run update inside a project. It checks the installed CLI/runtime, asks before migrations, refreshes generated runtime files, and preserves project memory files.
