Commands

The commands worth remembering.

Use spectra below if you installed the native binary. Otherwise use ./.spectra/bin/spectra from the project root.

spectra index

Builds .spectra/cache/index/repo-index.json, a disposable map of modules, dependencies, projects, and test targets. Run it after bootstrap, build-file changes, or when context feels stale. 

spectra index
spectra index --check
spectra index --explain

spectra onboard

Drafts the project brief from repo facts and your answers. It is most useful while projectbrief.md is still mostly a template. 

spectra onboard
spectra onboard --force

spectra context

Loads role-aware context for an agent or human session without dumping the whole repository into the prompt. 

spectra context --role planner --goal discover
spectra context --role implementer --goal implement

spectra check

Validates the installed Spectra layer. Use it after setup, after spec/context changes, and before approval or release decisions. 

spectra check
spectra check --base main --head HEAD

spectra verify

Aggregates release-grade confidence signals and tracked feature items. 

spectra verify
spectra verify --scope app --item FEAT-001

Advanced commands

Top-level operations such as approvals, evals, diffs, skills, and adapter generation. spectra admin <command> remains a compatibility alias. 

spectra approve --stage implementation-approved
spectra eval FEAT-001 --suite smoke
spectra adapters --agents codex,claude --target .
