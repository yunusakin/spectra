Workflow

A small loop for repeated agentic work.

Spectra is not another project-management system. Its job is to keep repo facts, task intent, validation, and release readiness close to the code.

Project workflow

spectra index
spectra onboard
spectra context --role planner --goal discover
spectra task --item TASK-001 --task-type feature --goal "Describe the change"
spectra context --role implementer --goal implement
spectra check
spectra status

Use approvals, evals, and release checks as needed for each project. spectra update refreshes the CLI and project runtime while preserving existing project memory.
