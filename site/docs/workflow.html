Workflow

A small loop for repeated agentic work.

Spectra is not another project-management system. Its job is to keep repo facts, task intent, validation, and release readiness close to the code.

Lite flow

spectra index
spectra onboard
spectra context --role planner --goal discover
spectra task --item TASK-001 --task-type feature --goal "Describe the change"
spectra context --role implementer --goal implement
spectra check
spectra status

Lite is the right default for personal or project-local use. It gives agents focused context and gives humans a repeatable health check without forcing approval gates.

Full flow

spectra context --role planner --goal discover
spectra check
spectra admin approve --stage product-approved
spectra admin approve --stage technical-approved
spectra admin approve --stage implementation-approved
spectra task --item FEAT-001 --task-type feature --goal "Implement the flow"
spectra context --role implementer --goal implement
spectra admin eval FEAT-001 --suite smoke
spectra verify --profile release
spectra admin approve --stage release-approved

Full is for teams that want formal specs, approvals, evals, and release gates. Start with Lite unless those controls are already useful.

Profile changes

spectra upgrade --profile full
spectra upgrade --profile full --agents codex,claude

upgrade changes the installed profile. update refreshes the installed CLI/runtime. Do not rerun adopt for normal upgrades.
