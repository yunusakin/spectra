Project-local CLI for AI-assisted development

Give humans and agents the same source of truth.

Spectra keeps project context, business rules, implementation intent, validation, and release confidence inside one repository-local spectra/ layer.

Get started View npm package 
npx spectra-pack@latest adopt .
./spectra/bin/spectra index
./spectra/bin/spectra onboard
./spectra/bin/spectra context --role planner --goal discover
./spectra/bin/spectra check
adopt index onboard context check verify

Install

Start with npm or the native binary.

Existing project

cd existing-project
npx spectra-pack@latest adopt .
./spectra/bin/spectra onboard
./spectra/bin/spectra check

No Node or npm

curl -fsSL https://raw.githubusercontent.com/yunusakin/spectra/main/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"
spectra adopt .
spectra status

Why Spectra

A small operating layer for repeated agent work.

Repo-aware context

spectra index builds a deterministic map of modules, dependencies, test targets, and evidence so agents do not need to reread the whole repository.

Durable business memory

Business rules and unresolved questions live under spectra/sdd/, with routing that loads only task-relevant context.

Lite or Full

Start with Lite for personal workflows. Upgrade to Full when a team needs approvals, evals, release gates, or generated agent adapters.

Validation and repair

check, verify, and doctor --fix keep generated runtime files, metadata, adapters, and release confidence inspectable.

CLI surface

Commands that stay boring on purpose.

spectra initCreate a new Spectra project.
spectra adoptAdd Spectra to an existing repository.
spectra indexRefresh the repo index used by context and verify.
spectra onboardDraft the project brief from answers and repo facts.
spectra contextLoad role-aware and goal-aware context.
spectra checkValidate the installed project layer.
spectra verifyAggregate release-confidence checks.
spectra doctor --fixRepair safe generated Spectra files.

Keep the product code yours. Keep the context findable.

Spectra owns spectra/. Your application, company docs, and repository layout stay in place.
