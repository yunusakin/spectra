Project-local AI development runtime

Context, checks, and release confidence for agentic work.

Spectra gives humans and agents one repository-local source of truth for project context, business rules, task intent, validation, and release readiness.

Start with Spectra View GitHub
spectra 
$ npx spectra-pack@latest adopt .
$ ./spectra/bin/spectra index
  ecosystems: maven
  modules: 20
  test-targets: 18

$ ./spectra/bin/spectra context --role planner --goal discover
  loaded focused project context

$ ./spectra/bin/spectra verify
  release confidence: ready
Repo-local Everything Spectra owns lives under spectra/.
Token-aware Index and route context before loading it into agents.
Agent-neutral Adapters point back to the same canonical project memory.

Install

Bootstrap once. Keep using the repo-local launcher.

Use npm for Node projects or the native binary when Node is not available. Both flows install the same project-local Spectra layer.

Existing project

cd existing-project
npx spectra-pack@latest adopt .
./spectra/bin/spectra onboard
./spectra/bin/spectra check

macOS / Linux native

curl -fsSL https://raw.githubusercontent.com/yunusakin/spectra/main/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"
spectra adopt .
spectra status

Workflow

A compact loop for repeated AI-assisted changes.

  1. 01 Adopt

    Create the project-local Spectra layer.

  2. 02 Index

    Map modules, dependencies, and test targets.

  3. 03 Onboard

    Draft the project brief from repo facts and answers.

  4. 04 Context

    Load the smallest useful role and goal context.

  5. 05 Verify

    Run checks and aggregate release confidence.

CLI surface

Small commands with clear jobs.

spectra indexBuild the deterministic repo index.
spectra onboardDraft projectbrief.md from repo facts.
spectra contextLoad role-aware context for the task.
spectra checkValidate the installed project layer.
spectra verifyAggregate release-confidence signals.
spectra doctor --fixRepair safe generated runtime files.
