Persistent, governed project intelligence

Context, rules and verified evidence for agentic work.

Agents execute. Spectra resolves, governs, traces, and verifies project knowledge. One repository-local source of truth for business rules, requirements, task intent, test evidence, and release readiness, usable by any coding agent.

Repo-local Project context and runtime live under .spectra/. Optional adapters use the root or tool paths their agents require.
Governed and verified Rules and requirements trace to the tests that verify them. Evidence has a scope. The review and release gates show what blocks.
Agent-neutral Adapters for Codex, Claude, Copilot, Cursor, Windsurf and Antigravity point back to the same canonical project knowledge.

Install

Bootstrap once. Keep using the repo-local launcher.

Use npm for Node projects or the native binary when Node is not available. Use init for a new project and adopt for an existing one. The default local Git mode keeps .spectra/ out of your repository. Installing the application and setting up a project are two separate steps. spectra update never changes a project.

Existing project

cd existing-project
npx spectra-pack@latest adopt .
./.spectra/bin/spectra onboard
./.spectra/bin/spectra check

macOS / Linux native

curl -fsSL https://raw.githubusercontent.com/yunusakin/spectra/main/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"
spectra adopt .
spectra status

Workflow

A compact loop for repeated AI-assisted changes.

  1. 01 Init / Adopt

    Create the project-local layer. Adoption records repository evidence, not business truth.

  2. 02 Onboard

    Capture the project brief from your interactive answers and optional repo index.

  3. 03 Context

    Load only the rules and modules a task touches, within a token budget.

  4. 04 Inspect

    Ask what governs a subject, or what changed files concern.

  5. 05 Verify

    Record test evidence, then gate review and release.

CLI surface

Small commands with clear jobs.

spectra indexBuild the deterministic repo index.
spectra onboardDraft projectbrief.md from interactive answers and optional repo index.
spectra contextLoad role-aware context for the task.
spectra inspectShow what governs a subject and why it is verified.
spectra checkValidate the installed project layer.
spectra verifyRecord test evidence, gate review and release.
spectra doctor --fixRepair safe generated runtime files.
