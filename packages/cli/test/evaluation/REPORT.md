## Metric definitions

- **selected**: resolved objects in the final pack; **candidates**: selected + resolved objects excluded for budget/anchor (routing index files are ignored).
- **required / relevant recall**: labelled objects selected ÷ labelled objects; reported separately and `n/a` when a case has none.
- **precision**: selected required-or-relevant ÷ selected non-acceptable objects; a selected object with no label counts as a false positive.
- **false negative cause**: `retrieval-miss` (never a candidate), `budget-exclusion`/`anchor-exclusion` (found, then dropped by selection).
- **budget levels**: `normal` is the role budget; `tight` / `very-tight` leave 50% / 20% of the case's candidate tokens as room for optional context.
