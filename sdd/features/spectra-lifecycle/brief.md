# Feature Brief

## Feature
Spectra lifecycle

## Intent
Describe, as canonical requirements, how a Spectra machine installation and a project move between versions: explicit migration, update that never touches projects, uninstall that never touches project files, recoverable schema changes and refusal of incompatible projects.

## Narrative
This brief is narrative-only. Canonical machine state lives in the adjacent YAML contracts. The requirements describe behavior that already exists (RULE-SPE-001..005); nothing here is new lifecycle behavior.
